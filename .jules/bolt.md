## 2026-11-10 - Caching LandArea aggregations in LandService
**Learning:** In FlatMeta, up to 15,000 tiles are kept in memory by `LandService`. Frequent user interactions like map clicks, pin navigations, URL routing, or searches call `area(orderId)`. Previously, `area(orderId)` called `this.areas()`, which performed full grouping of all tiles into `Map<string, LandTile[]>` and trigonometric centroid calculations for each area, followed by an O(N) array search. On 5,000 tiles across 500 areas, 100 lookups caused a blocking 1.2+ second freeze on the main JavaScript thread.
**Action:** Always maintain a memoized area list and an indexed `Map<orderId, LandArea>` in `LandService` that is invalidated only when the underlying tile set changes via `publish()`. Use the map for O(1) lookups.
